## ¿De qué trata el proyecto?

Imagina que quieres viajar desde **Bogotá hasta Buenos Aires**, pero no sabes cuál es la ruta más económica, cuál tarda menos o cuál te permite visitar más destinos con el dinero que tienes. **SkyRoute Planner responde exactamente eso.**

El proyecto modela una red de aeropuertos latinoamericanos como un **grafo** — una estructura matemática donde cada aeropuerto es un punto y cada ruta aérea es una conexión entre ellos — y sobre esa red aplica algoritmos para encontrar caminos óptimos según lo que el usuario priorice.

Pero va más allá de calcular rutas: el sistema **simula el viaje completo**. El usuario se mueve de aeropuerto en aeropuerto tomando decisiones en tiempo real — qué actividades hacer en cada ciudad, si necesita trabajar para reponer su presupuesto, y qué pasa cuando una ruta se cancela a mitad del camino.

---

## ¿Qué queremos lograr?

> El objetivo central es demostrar cómo los algoritmos de grafos resuelven problemas reales de planificación y toma de decisiones, a través de una interfaz visual e interactiva.

| # | Objetivo |
|---|----------|
| 1 | Encontrar la ruta más corta, más rápida o más económica entre dos aeropuertos |
| 2 | Generar itinerarios automáticos que maximicen los destinos dentro de un presupuesto o tiempo disponible |
| 3 | Simular un viaje dinámico donde el usuario toma decisiones en cada parada |
| 4 | Responder a imprevistos: si una ruta se bloquea, el sistema recalcula automáticamente el camino alternativo |
| 5 | Generar un reporte final del viaje con gastos, actividades y destinos recorridos |
